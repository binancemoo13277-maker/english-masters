Netlify-ready landing page that keeps the earlier red long-form sales layout while using original/local artwork and rewritten copy.

Includes:
- public/index.html — landing page
- public/admin.html — admin panel
- netlify/functions — content, orders, health APIs

- price 15 JOD

- Neon persistence
- order filters, single/bulk delete, CSV export
- Meta Pixel field/events

Required Netlify environment variables:
- DATABASE_URL
- ADMIN_PASSWORD
